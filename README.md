# Glitched Out


Core:
- 2D Sidescrolling Plattformer

Style:
- Pixelart

Music:
- Chiptune

Narrative: Present day
- Person buying a buggy game


## Idea Sketching 

1. Glitches
    - Things hurt the player
    - Sometimes they don't >>> Glitch
2. Looping
    - 'Exit 8" - Rerun the same level if the player misses something
    - Pathing to different routes in a level
3. Progressive loss of functions
4. Multiple layers of a level
    - Layer 1: Normal playworld
    - Layer 2: Challenging playworld
5. Meta-Narrative: Playing a player that plays the game

## SRS

### Functional

1. Move left/right
2. Player can Jump
3. Game Glitches
4. Physics Engine (x,y Positioning)

### Non-functional

- Godot: Small, easy to use
- Unity: Huge, but specialized person
